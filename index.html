ℹ How to Use the Map
  • Total Country Assets: Click the "Total Country Assets" button at the top of the sidebar panel anytime to pop up a comprehensive dashboard summary of all grids across the entire country.
  • Select by Island: Use the island drop-down menu to quickly switch or filter focus across different island groups.
  • Selection Modes: Toggle between Single, Multi, or use the Rectangle and Polygon drawing tools on the map toolbar to select multiple grids at once by drawing boxes or custom shapes.
  • Report Download: Use the "Download Report" button in the sidebar panel to export a formal valuation document titled "Replacement Costs (USD)" as a PDF including the national flag.
Note: Each grid contains estimated replacement costs of all major assets, apart from agriculture and airport runways.
